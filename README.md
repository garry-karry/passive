# Тренажёр колкостей

Тренажёр для команды Customer Success по воркшопу «Пассивная агрессия в работе». Один файл `index.html`, без сборки и без зависимостей.

- **Раунд:** 8 ситуаций от мягких к жёстким, выбор ответа на время (45 секунд, можно выключить), разбор каждого варианта и названная ловушка.
- **Свой ответ:** пишете ответ своими словами и сверяетесь с эталоном и чек-листом.
- **Итоги:** точность, лучшая серия и частые ловушки. Прогресс хранится только в браузере (localStorage).

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages: Settings - Pages - Deploy from a branch - `main` / root.

Шрифты (Onest, Unbounded, JetBrains Mono) подгружаются с Google Fonts. Без интернета страница работает на системных шрифтах.

## Общая таблица команды (по желанию)

GitHub Pages ничего не хранит, поэтому таблица ведется в Google Таблице через Apps Script.

1. Создайте Google Таблицу. Расширения - Apps Script. Вставьте код из `apps-script.gs`.
2. Развернуть - Новое развертывание - Веб-приложение. Выполнять от имени: я. Доступ: все.
3. Скопируйте адрес веб-приложения (заканчивается на `/exec`) и вставьте в `index.html` в константу `TEAM_URL`.
4. Появится вкладка «Команда». Результат уходит после раунда, если на вкладке «Раунд» указано имя.

Адрес виден всем, у кого есть страница, поэтому в таблицу может написать любой. Для внутренней команды этого достаточно. Имена и результаты видят все, кто открывает страницу.

## Как добавить ситуацию

В `index.html` найдите массив `S` и добавьте объект по образцу: уровень `lvl` (1-3), отправитель, канал, текст сообщения, четыре варианта (`ok:1` у лучшего, у остальных `trap` и `why`), `key`, эталон `ref` и список `crit`.
